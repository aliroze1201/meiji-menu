## 🚀 Déploiement sur GitHub Pages

1. **Créez un nouveau repository** sur GitHub nommé `meiji-sushi-grill`
2. **Uploadez les fichiers** (`index.html`, `README.md`, `LICENSE`)
3. Allez dans **Settings → Pages**
4. Sous **Source**, sélectionnez `main` branch et `/ (root)`
5. Cliquez **Save**
6. Votre site sera disponible à `https://VOTRE-USERNAME.github.io/meiji-sushi-grill/`

## 🖼️ Ajouter vos propres photos

Pour remplacer les visuels par de vraies photos de vos plats :

1. Créez un dossier `images/` dans le projet
2. Ajoutez vos photos (format `.jpg` ou `.webp`, idéalement 800×500px)
3. Dans `index.html`, remplacez chaque bloc :

```html
<!-- Avant -->
<div class="card-photo photo-salmon"><span class="food-icon">🍣</span></div>

<!-- Après -->
<div class="card-image"><img src="images/mon-plat.jpg" alt="Nom du plat"></div>
```
